1. Propósito ou justificativa do Projeto

Criar uma presença digital para a confeiteira Manu (Doces e Bolos da Manu), hoje dependente de conversas soltas no WhatsApp e Instagram. O site apresenta o cardápio de bolos personalizados, organiza o pedido (tema, tamanho, data da festa) e envia tudo pronto para o WhatsApp dela, reduzindo erros e idas e vindas na combinação do pedido.

Como projeto acadêmico, ele também serve para aplicar HTML, CSS e JavaScript em um caso real e publicar o resultado na internet.

2. Objetivos do Projeto

  • Publicar um site de página única (Home, Sobre mim, Produtos e Contato) no GitHub Pages. Verificação: o endereço público abre sem erros.
  • Exibir o cardápio com 10 temas de bolo, cada um com tamanho e preço. Verificação: os 10 cards aparecem com foto e opções de tamanho.
  • Permitir montar um carrinho e enviar o pedido pronto ao WhatsApp da Manu. Verificação: ao finalizar, o WhatsApp abre com nome, data, itens e total corretos.
  • Funcionar bem em celular e computador. Verificação: a página se ajusta às duas larguras, com menu próprio no celular.

3. Requisitos de alto nível

  • Página única com as seções Home, Sobre mim, Produtos e Contato.
  • Cardápio com foto, descrição e escolha de tamanho para cada bolo.
  • Carrinho lateral com adicionar, remover e total.
  • Formulário de pedido com validação de nome, WhatsApp e data (mínimo de 4 dias de antecedência).
  • Envio do pedido formatado para o WhatsApp da Manu.
  • Layout responsivo (celular e computador).

4. Premissas

  • A Manu fornece os preços reais, o texto da seção "Sobre mim" e uma foto dela; até lá, valem os dados provisórios.
  • Os pedidos são combinados e confirmados pelo WhatsApp; o site não faz pagamento online.
  • O GitHub Pages permanece disponível e gratuito durante o projeto.

5. Restrições

  • O foco do projeto é HTML, CSS e JavaScript; o código deve ser simples, comentado em português e fácil de explicar.
  • A hospedagem é o GitHub Pages, que só serve arquivos estáticos e não executa PHP.
  • Sem banco de dados e sem frameworks; o carrinho fica guardado no navegador.
  • Projeto acadêmico, com prazo definido pelo professor e sem orçamento.

6. Descrição do Projeto em alto nível

O site é uma landing page estática. O HTML traz a estrutura e os cards dos bolos, o CSS cuida do visual e da responsividade, e um JavaScript curto controla o menu, o carrinho (guardado no navegador), a validação do formulário e a montagem da mensagem enviada ao WhatsApp. O código é publicado no GitHub e servido pelo GitHub Pages. Existe também uma versão anterior em PHP, mantida no repositório apenas como referência, que não roda na hospedagem.

7. Limites do Projeto

  • Dentro do escopo: site de apresentação e pedido via WhatsApp, publicado no GitHub Pages.
  • Fora do escopo: pagamento online, login de clientes, painel administrativo, controle de estoque e armazenamento de pedidos em servidor.

8. Riscos de alto nível

  • Preços, texto e foto da cliente ainda não entregues, deixando o site com conteúdo provisório.
  • Mudança de orientação do professor sobre o foco ou as tecnologias (já aconteceu uma vez: o foco passou a ser HTML e CSS).
  • Carrinho guardado só no navegador: se o cliente limpar os dados do navegador, perde os itens escolhidos.
  • Falha ou instabilidade do GitHub Pages ou do WhatsApp, que impediria a publicação ou o envio do pedido.
